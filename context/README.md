# Context

Canonical reference documents that provide project, architecture, and domain context to agents. These are not rules or procedures — they're factual descriptions of the environment an agent operates in.

## What Belongs Here

- Project structure overviews
- Architecture decision records (ADRs)
- Domain glossaries (sanitized)
- Technology stack references
- Integration / API documentation

## What Does NOT Belong Here

- Procedural workflows (those are **skills**)
- Coding conventions (those are **rules**)
- Agent personas (those are **agents**)
- Secrets, connection strings, internal URLs (sanitize everything)

## Format

Standard markdown. No special frontmatter required — the filename is the identifier.
